# AIチーム委任プランナー

「やりたいこと」を入力すると、仕事を3〜4人のAIエージェント役に分解し、各担当のアクション・成果物・人間確認ポイントをカードで表示するWebアプリです。

## 特徴

- 外部AI APIを使わないルールベース設計
- 入力内容や難しさに応じて3〜4役の委任プランを生成
- 公開・予算・契約など、人の判断が必要なポイントを明示
- スマートフォンとデスクトップに対応

## ローカル実行

Node.js 22.13.0以降が必要です。

```bash
npm install
npm run dev
```

ビルドとテスト:

```bash
npm run build
npm test
```

## データと料金

入力内容は外部APIへ送信しません。外部AI APIを使用しないため、API利用料金も発生しません。
